A new look: the swatchbook

Nov 10, 2026

Every preset is now printed like a strip from a lighting-gel swatchbook: its catalog number, its name and maker, and a graph of bass, mid and treble with the sounds it reacts to lit. The chrome is matte black card that keeps one amber for whatever is on or playing and leaves every other colour on screen to the preset.

The aesthetic compass

Nov 8, 2026

A draggable map of every previewed preset, projected from the same visual embeddings that power search. Drag from organic liquid to geometric wireframe, or from hypnotic and minimal to reactive and chaotic, and the nearest look plays.

Pinch and twirl the stage

Nov 8, 2026

On a touchscreen, two fingers now steer the picture: pinch to zoom and twirl to rotate, starting from whatever the preset is already doing. One-finger swipes still change presets.

Sensory mood dials

Nov 8, 2026

Overall intensity, predictability, and a breathing pace. The dials lower the brightness ceiling, soften motion and contrast, smooth sudden jumps, and can breathe with you — and they can never raise the stage above the flash governor's limit.

Hands-free voice commands

Say "next", "calm", "breathe" or "full screen". Recognition runs on your device with the browser's local speech mode, and the switch only appears where the browser can keep audio from leaving it.

Added

  • **Publish a public video link…** publishes a four-second silent clip of the running preset, with its source code, and returns a `/s/<id>` page whose Open Graph tags carry the clip, so chat apps that read `og:video` show a playable card. The browser uploads quantized frames and the preset code, never audio. The Worker encodes a GIF and a JPEG poster, converts the GIF once to an H.264 MP4 through Cloudflare's Media binding, and serves the MP4 from R2 with byte ranges; only a record with a finished MP4 gets `og:video`. Uploads are same-origin, bounded in bytes, frames, dimensions and duration, and limited to three per IP a minute. Share pages are `noindex,follow`, the recipient runs the published code from an inert payload on the same origin, and the dialog hands back a token that deletes the record and every media file. The home page and `?preset=shifter-curlique` carry a curated clip (19,007 bytes at 192×108) (#1555, #1572).
  • More actions → Share link has an **Embed** button, and the palette has Copy embed code (`copy-embed-code`). Both copy an `<iframe>` for the playing preset (`?embed=true&preset=<id>` on the page's own origin, titled with the preset and its author, 800×450 and responsive, `loading="lazy"`); before, embedding needed the `?embed=true` flag, which no screen mentioned. The snippet never carries a draft, and with unsaved edits the button says so. A preset made or imported in this browser has no embed, because no other browser can load its id. The oEmbed provider builds its `html` from the same code, so its iframe gains the responsive style, `fullscreen` and lazy loading (#1584).
  • The editor's code names the sounds that drive each field: a line that sets an audio-driven field ends in its sources, as in `zoom=0.999514 ← bass, mid, treb`, read from the same dataflow analysis as the Tune chips. A field's literal line is tagged, and so is the last assignment to it in the per-frame or per-pixel equations; an assignment a later one overwrites is not. A newly loaded preset scrolls to the first tagged line (line 208 on the first-run preset). Before, only the Tune chips made this claim, and on a first open two of 45 were on screen at 1280×720 and none at 390×844. The tags are `aria-hidden`; the chips keep the accessible list (#1587).
  • Find a preset has a **By reference** mode. Describe a look, and Stims ranks editable starting presets on the device with Browse's text scorer and the EmbeddingGemma 2 visual-term vectors; the description is not uploaded. An optional reference image lets Clef Omni pick among up to 12 of the matches, or decline. Open one in the editor and mark it accepted or rejected: the outcome goes to a local IndexedDB store (at most 100 episodes and 32 MiB, oldest evicted first), and later searches can reuse an accepted reference (#1551, #1552).
  • Telemetry records which actions run, and from which surface: `action:<id>` from `dock`, `menu`, `palette`, `key`, `gesture`, `pad`, `landing`, `browse`, `editor`, `settings`, `cue` or `other`, each counted once per page load and at most 150 per load. The id is the command-palette id, so `E` and the menu's Edit preset code both report `action:open-editor`, and an id outside the app's own pattern is not sent. The beacon carries only the context fields every beacon already has, the start page says "Usage is counted as anonymous events — no account", and `telemetry:report` adds an actions-by-surface table (#1552, #1581).
  • Telemetry beacons carry the OS family (`android`, `ios`, `windows`, `macos`, `linux` or `other`), the browser engine (`chromium`, `webkit`, `gecko` or `other`), the engine's major version, and a flag for an Android WebView. The browser works these out and sends only the classes: no OS version, device model or browser name. Crash beacons no longer include the raw user-agent string, which the Worker never stored. `telemetry:report` adds audible starts by OS and device, and by engine major version.
  • The agent verb `edit-source` (`run('edit-source', { source })` or `{ append }`) changes the preset code the way typing does: the session turns dirty, the edit is saved as the preset's draft, and the leave-page guard sees it, where `set-field` writes only the running VM. The result carries the editor state (`dirty`, `errorCount`, diagnostics), and `bun run ctl` waits for the engine before running it (#1593).
  • `bun run live` acts on the tab a person is watching. Under `bun run dev`, the dev server's hot-reload socket relays commands to the visible, focused tab and writes its events, state and last capture to `scratch/live/`; saving `scratch/live/preset.milk` applies it as preset source, and saving `pattern.js` plays it as a Strudel pattern.   • `bun run test:budget` ranks gate and package tests by the CPU they burn, subprocesses included, and predicts each test's wall time at a target load (default 4 × cores), so its verdict does not depend on how busy the machine is during the run; it exits 1 when a test on bun's 5 s default would overrun below that load. Firefox and WebKit get a first-run smoke e2e: the landing, the note that tab and YouTube audio need Chrome or Edge, and demo audio going live on WebGL (#1591, #1593).
  • The offline embedding script takes `--dtype` (`fp32|fp16|q4|q4f16|q8`, default `q8`), so a full re-embedding pass can run the model repo's lower-precision weights. The image index records the dtype, and a dtype change must regenerate every derived artifact in the same pass (#1539).
  • New docs: `PRODUCT.md` (who Stims is for, its positioning, and what no surface may claim), `docs/UPSTREAM_CONTRIBUTIONS.md` (every upstream PR and proposal, with its status) and `docs/LEARNING_LOOPS_SPEC.md` (the nine model-assisted learning loops, with their stores, review, privacy and release gates) (#1550, #1570, #1588).
  • Four ways to steer the visuals by feel instead of by parameter name. Settings → Accessibility → Sensory mood has three dials: grounding vs stimulation (a brightness ceiling, motion dampener and contrast scale that compose with the flash governor), harmonic predictability (smooths q-variable jumps once per frame), and a paced breathing guide (a 4–12 s expansion LFO). Browse's aesthetic compass projects the shipped 256-d preview vectors onto a draggable 2D plane and plays the nearest preset on release, skipping presets Reduce flashing hides (#1679, #1681, #1682, #1683, #1684).

Changed

  • The chrome is redesigned as a lighting-gel swatchbook. Every preset prints like a numbered strip of black card: its catalog number (from `catalog.json`'s `order`), name, maker, and a live graph of bass, mid and treble that lights the bands its drawn output reads, from the same dataflow analysis as the editor's sound tags. The landing is a riveted cover sheet over the running preset, the dock a strip with that graph along its top edge, the title card a swatch that swings in on its rivet, and Browse prints one catalog number per tile. Amber `#ffb21a` is the only colour the chrome emits and marks only what is on, selected, playing or focused; the primary action is a white tab. Pathway Extreme (width axis) and Atkinson Hyperlegible Mono replace Archivo and Martian Mono, the social cards and edge share card are set in the same faces, and the app icon is a swatch strip. `DESIGN.md` records the system.
  • Preset pages link the topic hubs that list them, under **Collections**, and name those collections in their descriptions. Their structured data credits each hand in a chain as its own person, and their breadcrumb runs through `/presets/`. Every page's JSON-LD now names the same site, and identifies MilkDrop by its Wikipedia and Wikidata records; hubs add breadcrumbs and a preset list, the course hub is a `Course`, and the technique glossary is a `DefinedTermSet`.
  • Reduce flashing is on by default for new visitors and for saved preferences that predate the setting; an opt-out you saved is kept. It used to start on only when the operating system asked for reduced motion. From a first visit, Browse, shuffle and autoplay leave out presets measured above the WCAG 2.3.1 limit, and the live governor dims detected strobing (#1573).
  • The start page leads with your own audio. The main button reads Start visualizer (was Play demo), the source chips sit under Connect your audio (was Or play your own audio), the showcase is Jump into an iconic look, and a `?preset=` page says Starting visualizer… instead of Starting with demo audio… (#1614).

The starter catalog and the Archivo font preload with `fetchpriority="high"`, the loading cover and the launch hero keep clear of the iOS home indicator, the service worker (shell v11) precaches the four starter-showcase thumbnails, and starter cards name the preset they play to screen readers (#1603).

The static signal field paints immediately and the page responds before the engine boots; in a Playwright run the first motion arrived 2.1 s after a scroll at 0.5 s and 4.9 s when nobody interacted. Five paired Lighthouse mobile trials put the median performance score at 85 against 79 for the idle-callback build (runs ranged 75–94 against 77–85, so this is recorded as a responsiveness change, not an FPS claim) (#1601).

Firefox and Safari also get "Tab, system and YouTube audio need Chrome or Edge." Side effects are named (Cast to a TV or Chromecast (starts a watch party), Reload (stops audio)); toggles show their state and flip their label (Save preset / Remove from saved); Pause reads Pause visuals, with "Sound keeps playing.", for the microphone, a tab and demo audio, and plain Pause for files and YouTube, which really stop; the cue deck's Take, Fade by hand and Skip are Play now, Play with a crossfade slider and Remove from queue; each AI control says "with AI"; and the dock's icon buttons show their name on hover and keyboard focus instead of in `title` tooltips that touch and keyboard users never saw (#1579).

The first press relabels the button (Delete for good), a second press within 4 s acts, and blur or Escape cancels. Each used to act on one press with no undo (#1579).

  • Two EEL rules follow the ns-eel2 source that MilkDrop 2 ships. `-2 ^ 2` is `-(2^2) = -4` on every tier (it was +4, the modern-EEL2 reading), and a `while()` condition counts as true only above the close factor (`|cond| > 1e-5`), so a condition that decays to 1e-6 ends the loop instead of running it to the iteration cap. No bundled preset writes `-a^b`, and all 558 `while()` statements in the corpus test a comparison or a logical result, so no bundled preset changes. All 82 `eel-conformance` cases are now pinned, and `packages/eel-conformance/docs/ns-eel2-source-audit.md` cites the file and construct behind each answer (#1567, #1595).
  • Audio analysis allocates less per frame. Writing the audio texture the GPU reads takes 1.050 µs a frame instead of 2.921 µs (292.08 ms → 104.96 ms over 100,000 frames), because each pixel is one 32-bit write instead of four byte writes and three `Math` calls. The AudioWorklet reuses its six per-tick result objects and its transfer list, the main thread reuses its buffer lists for each worklet message, `getFrequencyFrame` returns one cached result per analyser instead of a new object every animation frame, and preset blends copy their typed arrays with `slice()`, about 35% faster in a benchmark (#1545, #1614).
  • The audio analyser's FFT folds windowing, bit reversal and the first two radix-4 stages into one pass, harmonic/percussive separation takes its 7-frame and 9-bin medians through branchless selection networks, and the WebGL mesh transform computes its zoom and scale reciprocals once per frame unless the per-pixel code writes them (`d867a7941`).

Security

  • Shared links are bounded before they are decoded. A `#code=z1~` link was inflated with no cap on the first render, so a short payload could expand to hundreds of megabytes, and the preset-set decoder capped memory but not time. Both reject compressed input longer than any link Stims writes (16,000 bytes) and cap the decoded size at 1 MiB of preset source and 4 KB for a set (#1548, #1598).
  • One frame's programs share a single budget of 2,097,152 loop iterations: the per-frame program, every per-pixel vertex, and every wave sample and shape instance together. The cap used to apply per call, so a `while(1)` in per-pixel code ran it at every mesh vertex, about 25 s of main-thread work per frame from one opened share link. The heaviest bundled preset needs 80,281 iterations a frame (`martin-city-of-shadows`), so none reaches the budget (#1598).
  • Preset equations also run under a wall-clock ceiling. A step that has spent 50 ms stops its loops and skips the remaining per-vertex and per-sample calls; init programs get 500 ms instead of an unlimited shared budget, and `getExecutionBudgetExceeded()` reports a truncated step. Compilation, shader work and geometry still have their own costs, and the live render path still runs on the main thread; the generated-preset reactivity probe compiles and steps untrusted source in a terminable worker with a timeout (#1600).
  • **Breaking for embedding pages:** the iframe bridge accepts commands from another site only when that site is the direct parent of an explicit embed (`?embed=true` or an alias).   • Custom shape instancing (`shapecode_N_num_inst`): per-frame shape code runs once per instance with `instance` and `num_inst` in scope. 304 bundled presets declare multi-instance shapes and 232 vary geometry by `instance` (`5e7bc5fb8`).
  • `randint`, `log10` and `gmegabuf` in the preset expression language (`c065a6823`).

Changed

  • Settings, the browse drawer and the dock are redesigned as a console-style workspace (#1081).
  • VM program blocks compile to one JavaScript function each instead of one per statement, taking VM CPU cost from 2.00 ms to 1.10 ms a frame (`c065a6823`).
  • The WebGPU compute VM reuses its readback buffers and packs its signal arrays (`97e9b640e`).
  • Fullscreen rendering quality, refresh targets and effects are tuned for flagship phones (`30f5b8d54`).
  • URL overrides are handled in one place, with a sanitized storage accessor and an override reset helper (`12dae71a9`).
  • The custom shape radius floor is 0.002 instead of 0.04, so MilkDrop's instanced dot fields keep their authored size (`5e7bc5fb8`).

Fixed

  • Microphone permission errors say what to do, and a missing or busy device falls back with its own message (`f75490c59`).
  • Microphone capture works on mobile browsers (`67bdc66c6`).
