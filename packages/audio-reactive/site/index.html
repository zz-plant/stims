From an AudioNode to numbers a renderer can use.

An AudioWorkletProcessor that computes an FFT, harmonic/percussive separation, spectral features and per-band beat envelopes off the main thread, plus the pure functions behind it for band levels, transients and beat tracking that run anywhere, and a Hermite interpolator that turns 43 Hz packets into a continuous curve for 240 Hz displays. Zero dependencies. The spectrum bytes match AnalyserNode.getByteFrequencyData, so it drops in without retuning anything downstream. Born in Stims, the visualizer at toil.fyi.

Wiring, as the page does it

const context = new AudioContext();
await context.audioWorklet.addModule('./lib/worklet.js'); // audio-reactive/worklet, bundled
const node = new AudioWorkletNode(context, 'frequency-analyser', {
  numberOfInputs: 1, numberOfOutputs: 1, outputChannelCount: [1],
  processorOptions: { fftSize: 1024, sampleRate: context.sampleRate, messageEvery: 1 },
});
source.connect(node);
node.connect(context.destination); // output is silence; keeps the node alive

node.port.onmessage = ({ data: packet }) => {
  const frequencyData = new Uint8Array(packet.frequencyData); // 512 bytes
  const waveformData = new Uint8Array(packet.waveformData);   // 1024 bytes
  const timeDomainData = new Float32Array(packet.timeDomainData);
  draw(packet.energy, packet.beatDetection, packet.harmonicPercussive, frequencyData);
  node.port.postMessage(
    { type: 'recycle-buffers', freq: [frequencyData.buffer], wave: [waveformData.buffer], timeDomain: [timeDomainData.buffer] },
    [frequencyData.buffer, waveformData.buffer, timeDomainData.buffer],
  );
};

The frame holding the click reads as broadband (flatness near 1, centroid near 11 kHz) and percussive (ratio near 1); the frames around it read as a tone near 440 Hz with a percussive ratio near 0.4.

import {
  analyseBlockBytes, buildHannWindow, buildTwiddleTable, createBeatTracker,
  createHarmonicPercussiveAnalyser, extractSpectralFeatures, getFrequencyBandLevels, getWeightedEnergy,
} from 'audio-reactive';

const window = buildHannWindow(fftSize);
const twiddles = buildTwiddleTable(fftSize);
const scratch = { real: new Float32Array(fftSize), imag: new Float32Array(fftSize) };
const spectrum = new Uint8Array(fftSize / 2);
const hpss = createHarmonicPercussiveAnalyser();
const beats = createBeatTracker();

for (let start = 0; start + fftSize <= samples.length; start += fftSize) {
  const block = samples.subarray(start, start + fftSize);
  analyseBlockBytes(block, window, twiddles, spectrum, scratch);
  const bands = getFrequencyBandLevels(spectrum, sampleRate);
  const energy = getWeightedEnergy(bands);
  const hp = hpss.analyse(spectrum, sampleRate);
  const beat = beats.update({ bands, weightedEnergy: energy, deltaMs: blockMs }, (start / sampleRate) * 1000);
}

Design notes

Condensed from the source docblocks; the README carries the long form.

Zero allocation in the worklet

process() runs on the real-time audio thread every 128 frames. Ring buffers, window, twiddles, scratch arrays and HPSS history are allocated once in the constructor. The only per-packet allocation is the set of ArrayBuffers posted to the main thread, and those are transferred, not copied; send them back with recycle-buffers and the processor pools up to 16 of each, so a steady state allocates nothing.

The AnalyserNode dB window

AnalyserNode.getByteFrequencyData maps magnitude through 20·log10 into [-100, -30] dB. Band levels, beat thresholds and the downstream signal processors in Stims were tuned against those bytes. An earlier linear mapping left realistic music (-20 to -40 dBFS) at byte values of 0–12 and flatlined every band, so analyseBlockBytes applies the same window and the worklet can replace an AnalyserNode on the same scale.

Median-filter HPSS

Fitzgerald (2010): a median across time (per bin, over 7 frames) suppresses transients and estimates sustained content; a median across frequency (9 neighbouring bins) suppresses narrow peaks and estimates broadband content. Wiener-style soft masks split each frame's energy into harmonic and percussive. It is a spectrogram measurement, not stem separation. Medians over at most 9 values use insertion sort. percussiveRatio is 0.5 in silence so it never emits NaN.

Hermite interpolation between packets

Packets arrive at the FFT block rate, about 43 Hz at 44.1 kHz / 1024, while displays refresh at 60–240 Hz; sampling the last packet produces staircase stepping. The interpolator keeps the last two packets with finite-difference velocities and evaluates a cubic Hermite spline between them: C1-continuous, clamped at zero, allowed to extrapolate 25 % past the newest packet so rendering never waits on audio.
