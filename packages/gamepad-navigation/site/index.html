gamepad-navigation focus navigation for controllers and TV remotes
Try it Mapping API GitHub npm

Move focus with a D-pad, a stick or a remote, over the DOM you already have.

One call polls the connected gamepad and turns it into focus: directions go to the nearest focusable element by geometry, A activates, B sends Escape, the bumpers step in document order, and a focused slider is nudged by its step. The keyboard can be treated as a TV remote, with Tizen and webOS key codes mapped, where that is what the keyboard is. Pure TypeScript, no dependencies.

Mapping

InputDoes
D-pad, left stick past axisThresholdFocus the nearest focusable element in that direction. Candidates are scored by distance along the axis plus 0.35 of the distance across it; none in that direction, and focus wraps in document order.
Left or right on a focused range inputAdd or subtract its step, clamped to min and max, and dispatch input.
Held directionRepeats after initialRepeatDelayMs, then every repeatIntervalMs.
A (button 0)Click the focused element; with nothing focused, focus the first one.
B (button 1)Dispatch an Escape keydown on the document.
LB, RB (buttons 4, 5)Previous and next in document order.
Open dialog or [role=dialog][aria-modal]Bounds every move; focus does not leave it.
Text input focusedDirections are left to the caret; only Escape is handled from the keyboard.
Keyboard, with keyboardNavigationArrows move, Enter/OK/Select activate, Backspace/Escape/Back/Exit go back, including the legacy Tizen and webOS key codes (10009, 461, 23).

API at a glance

initGamepadNavigation(options?)Installs the listeners and returns the function that removes them.
shouldHandleBackKey(event), shouldHandleEnterLikeKey(event)The remote key classifiers, for a handler of your own.
shouldDispatchEscapeFallback(originKey)Whether a back key should re-dispatch Escape (not when it already was one).
DEFAULT_FOCUSABLE_SELECTORThe default focusable set, the browser's Tab order plus details > summary.

Options and the measurements behind them are in the README.
