Record any canvas to a video file, cropped or natively rendered to the size you need.

One class around canvas.captureStream and MediaRecorder: pick a preset, start, stop, get a Blob. A 9:16 or square preset is recorded from a copy cropped to fill the frame, or, when your renderer can draw at that size for the duration, from the renderer itself. 4K is only ever native. An audio stream is cloned onto the file. Pure TypeScript, no dependencies.

How frames reach the file

Native

For 4K, 9:16 and 1:1 with a CanvasVideoExportRuntime, the host renderer is asked to draw at the preset size (beginNativeCapture) and the source canvas itself is captured. Restored when the recording stops, or at once if the recorder cannot start.

Copied

Otherwise a copy cropped to fill the preset size is painted every frame (createCanvasFrameCopy) and captured. The copy is sized before the first frame, so a capture never starts at 300x150.

Yours

createFrames replaces both. Stims paints its copy from the render loop's frame notification with the dimming its stage shows over the canvas baked in.

4K is only native

A Full HD canvas scaled up is not 4K, so without a runtime the 4K preset is refused with a reason rather than upscaled.

Audio

The runtime's audio stream, when it has one, is cloned track by track onto the recording; the clones are what gets stopped, never the originals.

Hidden tabs

onRecordingChange reports start and end, for a host that throttles rendering in a hidden tab and must keep going while a recording runs.
